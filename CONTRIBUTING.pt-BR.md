# Contribuindo

Contribuições para o Guia de Arquitetura de Decisão são bem-vindas.

O projeto é aberto e evolutivo. As contribuições podem incluir melhorias no conteúdo existente, novos conceitos, exemplos práticos, referências, traduções, correções e perspectivas críticas.

## Issues

Use as issues para propor ideias, discutir problemas ou sugerir mudanças relevantes.

Sempre que possível, apresente:

* Contexto e motivação
* Mudança proposta
* Exemplos ou referências relevantes

## Pull Requests

Mantenha os pull requests focados e explique o que foi alterado e por quê.

Para mudanças relevantes, abra uma issue antes para discutir a proposta.

## Diretrizes de Conteúdo

As contribuições devem:

* Focar em conceitos, em vez de prescrever uma metodologia universal.
* Tornar explícitos o contexto, as premissas e as restrições.
* Diferenciar conceitos de frameworks ou métodos específicos.
* Evidenciar incertezas e trade-offs quando relevantes.
* Priorizar exemplos concretos e referências confiáveis.

O objetivo é desenvolver uma linguagem comum para compreender decisões em diferentes contextos, e não criar mais um framework universal.

## Discussões

Diferentes perspectivas são bem-vindas. Critique ideias, premissas e argumentos, não pessoas, e mantenha as discussões construtivas e baseadas em evidências.
